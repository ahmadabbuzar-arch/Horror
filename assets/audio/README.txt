Optional ambient audio files for THE LAST VILLAGE (Part 1)
Place these files in this folder:
- wind.mp3         looping village wind ambience
- crickets.mp3     looping distant insects/crickets
- wood_creaks.mp3  subtle wooden-house creaks

The audio system is already wired into the game. Missing files are optional and will not stop gameplay.
Playback begins after the first user interaction because mobile browsers block autoplay.
Recommended: short seamless loops, moderate volume, no sudden loud peaks.
