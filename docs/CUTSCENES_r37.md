# r37 — Opening cinematic

- Added a realtime Three.js opening sequence using the existing damaged sedan and SAAYA model.
- Camera moves through six cinematic shots with letterbox bars and Hindi captions.
- Existing car lights and sound effects are used; no replacement environment or new large assets.
- Player movement is locked during the sequence and restored at the end. Skip button is available.
- This is an opening cutscene only; mission flashbacks and ending cinematics are not yet implemented.
- Static checks are not a substitute for browser/Android playback testing.
